# InsAcc Enterprise Documentation Suite

**Master Reference Specification**: [MASTER_ARCHITECTURE.md](file:///Users/t6ux/InsAcc/docs/MASTER_ARCHITECTURE.md)

This directory contains the modular 9-volume enterprise documentation suite, configuration templates, automated operational scripts, and assets for the InsAcc platform.

## Directory Structure Overview

- `Volume_01_Installation_Guide/`: Installation, system requirements, build & verification.
- `Volume_02_Data_Management_Guide/`: Persistence, schema versioning & migration plans.
- `Volume_03_System_Administrator_Guide/`: Administration, COA, access control & period closing.
- `Volume_04_End_User_Manual/`: Operational manuals for investments, properties, PDCs & reports.
- `Volume_05_Interface_and_Integration_Spec/`: IPC bridge, import/export schemas & REST API spec.
- `Volume_06_Developer_Architecture_Guide/`: CQRS architecture, double-entry engine & testing.
- `Volume_07_Disaster_Recovery_Guide/`: Backup, disaster recovery & state restoration runbooks.
- `Volume_08_Security_Guide/`: Electron security, audit findings & security hardening.
- `Volume_09_Appendices/`: Accounting events, posting rules, key dictionary & glossary.
- `assets/`: Mermaid diagrams, images, and export styling templates.
- `configs/`: Production configuration templates (Nginx, PostgreSQL, PM2, Systemd, env).
- `scripts/`: Deployment, setup, backup, and restore shell scripts.
