# Documentation Assets

**Master Reference Specification**: [MASTER_ARCHITECTURE.md](file:///Users/t6ux/InsAcc/docs/MASTER_ARCHITECTURE.md)

This directory contains visual assets, diagrams, screenshots, and export templates for the InsAcc documentation suite.

## Subdirectories
- `diagrams/`: Mermaid.js source diagrams for system architecture and accounting workflows.
- `images/`: High-resolution UI screenshots and visual assets.
- `templates/`: Pandoc typst / LaTeX and Microsoft Word export reference templates.
