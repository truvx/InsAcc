# Enterprise Document Templates

**Master Reference Specification**: [MASTER_ARCHITECTURE.md](file:///Users/t6ux/InsAcc/docs/MASTER_ARCHITECTURE.md)

This directory contains standardized, reusable Markdown document templates for the InsAcc documentation suite. Every template contains the mandatory 15 enterprise sections (Title, Revision History, Table of Contents, Purpose, Scope, Audience, Prerequisites, Warnings, Notes, Main Content, Summary, Appendix, Glossary, References).

## Template Catalog

1. **[Book_Template.md](file:///Users/t6ux/InsAcc/docs/enterprise/assets/templates/Book_Template.md)**: Full volume / book specification template.
2. **[Chapter_Template.md](file:///Users/t6ux/InsAcc/docs/enterprise/assets/templates/Chapter_Template.md)**: Individual volume chapter template.
3. **[Appendix_Template.md](file:///Users/t6ux/InsAcc/docs/enterprise/assets/templates/Appendix_Template.md)**: Technical reference appendix template.
4. **[Configuration_Template.md](file:///Users/t6ux/InsAcc/docs/enterprise/assets/templates/Configuration_Template.md)**: Infrastructure configuration template.
5. **[API_Template.md](file:///Users/t6ux/InsAcc/docs/enterprise/assets/templates/API_Template.md)**: IPC channel / REST API specification template.
6. **[Troubleshooting_Template.md](file:///Users/t6ux/InsAcc/docs/enterprise/assets/templates/Troubleshooting_Template.md)**: Operational diagnostics and troubleshooting runbook template.
7. **[Administrator_Guide_Template.md](file:///Users/t6ux/InsAcc/docs/enterprise/assets/templates/Administrator_Guide_Template.md)**: System administrator operational guide template.
8. **[User_Manual_Template.md](file:///Users/t6ux/InsAcc/docs/enterprise/assets/templates/User_Manual_Template.md)**: End-user operational manual template.
9. **[Developer_Guide_Template.md](file:///Users/t6ux/InsAcc/docs/enterprise/assets/templates/Developer_Guide_Template.md)**: Core developer architecture guide template.
